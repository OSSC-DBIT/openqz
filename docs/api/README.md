# API reference

- **Live, interactive:** `/api/docs` on any running OpenQZ (Swagger UI, generated by FastAPI).
- **Checked-in spec:** [`openapi.json`](openapi.json). CI regenerates it and fails if it differs, so it always matches the code.

Regenerate after changing an endpoint:

```bash
docker compose -f compose.yaml -f compose.dev.yaml run --rm --no-deps -T migrate \
  python scripts/export_openapi.py > docs/api/openapi.json
```

## Conventions

| Topic | Rule |
| --- | --- |
| Base path | `/api/v1` |
| Auth | `Authorization: Bearer <access token>` (15 min). Refresh with `POST /auth/refresh` (httpOnly cookie, rotates). |
| Errors | `{"detail": {"code": "machine_code", "message": "Human text"}}` for business errors; `{"detail": [...]}` for validation (422). |
| Rate limits | Login, Google sign-in and forgot-password: per IP and per email. Room joins: 20 per minute per user. 429 when exceeded. |
| Marks | Marks are decimals sent as strings in typed responses (for example `"2.50"`). |
| Times | ISO 8601 with time zone (UTC from the server). The player uses `server_now` to correct device clocks. |

## Endpoint groups

| Tag | Prefix | Who |
| --- | --- | --- |
| auth | `/auth/*` | everyone: login, Google, refresh, logout, change / forgot / reset password, config |
| users, audit | `/users`, `/audit` | admin |
| organisation | `/departments`, `/sections`, `/subjects`, `/assignments` (faculty mapping), `/me/teaching`, `/me/sections` | admin; faculty and students read their own |
| imports | `/imports` | admin |
| activities | `/activities`, `/me/classes` | faculty, club organisers (own) and admin; `section_ids` lists the classes; `POST /activities/{id}/assign` with `room: true` hosts a room |
| results | `/activity-assignments` | faculty, club organisers (own) and admin: settings, stop / allow joins, `new-code`, reports, CSV / Excel, grading, release |
| play | `/me/activities`, `/me/assignments/{id}/start`, `/attempts/*`, `/join`, `/join/{code}` | students (own attempts only; join any open room) |
| media | `/media` | upload: faculty / admin; read: any signed-in user |
| integrity | `/integrity/events` | write: signed-in users; read: faculty / admin |
| health | `/health` | public |
